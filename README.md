# Rumah Makan Sedap

Website landing page sederhana untuk restoran dengan navbar, hero section, dan menu favorit.

## Deskripsi
Proyek ini dibuat menggunakan HTML dan CSS untuk menampilkan tampilan landing page restoran dengan nama **Rumah Makan Sedap**.

## Struktur File
- `bljr.html` - struktur halaman utama
- `rasya.css` - styling halaman
- `index.html` - file tambahan yang tersedia di project

## Cara Menjalankan
Buka file `bljr.html` langsung di browser, atau jalankan server lokal sederhana jika diperlukan.

## Fitur
- Navbar dengan logo dan 3 menu
- Hero section untuk promosi restoran
- Kartu menu favorit
- Tampilan responsive sederhana
